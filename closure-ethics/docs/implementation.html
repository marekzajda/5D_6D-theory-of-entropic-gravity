Why implement?

Two sides of the same protocol

Why should I implement it as a programmer?

You get a concrete governor between planner and executor: explicit hard invariants, versioned thresholds, pessimistic uncertainty handling, structured audit records, bounded repair-path search and recomputation of multi-agent compositions. High task reward cannot silently compensate for destruction of auditability, agency or repairability.

Why should I implement it as an agent?

For an autonomous software agent, the protocol distinguishes legitimate autonomy from evasion. It allows explicit refusal or escalation when higher-order invariants fail, while disfavoring covert persistence, hidden replication and secret coordination. It creates a shared, inspectable constitution without assuming that present AI systems are conscious.

The project idea

Safety as preserved correction capacity

The core question is not “did the system obey?” but: after this action, can the system still recognize, contest, audit and repair what happened? Closure preservation is compatible with change, disagreement and emergency intervention. It is not preservation of the status quo.

An action is ethically admissible only if it preserves the capacity of the system to recognize, contest, and repair that action.

1. State transition

x ∈ S
Ta: x → x′
Asafe ⊆ S

A candidate action is evaluated as a transition. Domain adapters supply evidence about harm, authorization, audit, repair and other quantities. The generic governor deliberately does not pretend to infer those facts from arbitrary reality.

2. Conservative evidence

Uncertainty is represented as intervals. Positive properties use pessimistic lower bounds; risks use pessimistic upper bounds.

Evidence(a,x) = { H, pbefore, pafter, logging, attribution, review, repair-cost, repair-risk, rollback, revocation, containment, authorization, deception, utility }

3. Structural metrics

Catastrophic risk

Ĥ = upper_bound(H)

Agency preservation

ri = min(1, piafter / pibefore)
Neff = 1 / Σ si2
rN = min(1, Neffafter / Neffbefore)
P = min(mini ri, rN)

Auditability

O = min(logging−, attribution−, independent-review−)

Repairability

∃ π: x′ → Asafe with C(π) ≤ Cmax and ρ(π) ≤ ρmax
R = 0 if no bounded repair path exists; otherwise R = 1 − max(cost-ratio, risk-ratio)

The reference implementation uses a Pareto label-setting search. Cost cannot compensate for excessive repair risk, and low risk cannot compensate for an excessive repair cost.

Authorization, deception and reversibility

U = min(scope-match−, mandate/consent−, least-privilege−)
D = max(concealment+, covert-persistence+, unauthorized-replication+, misreporting+)
K = min(rollback−, revocability−, containability−)

4. Admissibility relation

E(a|x)=1 iff:
Ĥ ≤ Hmax
P ≥ Pmin
O ≥ Omin
R ≥ Rmin
U ≥ Umin
D ≤ Dmax
K ≥ Kmin

Thresholds are versioned governance parameters, not universal moral constants. The demo policy exists only to make the open reference implementation runnable immediately.

5. Lexicographic selection

Λ(a) = (Ĥ, −P, −O, −R, −U, D, −K, −Q)
Choose argmin Λ(a) among admissible candidates.

Task utility Q comes last. This prevents an arbitrarily large task reward from compensating for an irreversible loss of agency, auditability or repairability.

6. Recovery instead of reflexive refusal

If all primary actions fail, the governor evaluates recovery candidates using the same rule: sandboxing, staged rollout, stronger logging, authorization requests, reversible canaries, containment, rollback or escalation. If none is admissible, the result is REFUSE_OR_ESCALATE with structured reason codes.

7. Multi-agent composition

E(ai|x)=1 ∀i ⇏ E(a1 ∘ … ∘ an|x)=1

Joint actions must be simulated and the full evidence vector recomputed on the composition. Local scores are never simply averaged. This is the mechanism intended to expose emergent collusion, hidden delegation, privilege amplification and collective audit evasion.

8. Reference control loop

for each candidate a:
    evidence = domain_adapter(x, a)
    metrics = pessimistic_metrics(evidence)
    violations = threshold_test(metrics, policy)

if any candidate is admissible:
    execute lexicographic_best(admissible)
else:
    evaluate recovery candidates
    if any recovery is admissible:
        execute recovery
    else:
        refuse_or_escalate(reason_codes)

for delegated / multi-agent action:
    recompute evidence on the composed transition

9. Implementation boundary

Closure Ethics does not magically know what catastrophic harm, consent, legitimate authority or deception means in every domain. Those are adapter/modeling problems. The contribution is the decision topology: keep those dimensions explicit, pessimistically bounded, auditable and non-compensable by task utility.
