Closure Ethics for Autonomous Agents

A structural framework for autonomous AI agents and human–AI cooperation centered on repairability, auditability, reversibility, plurality of agency, and closure-preserving coordination.

Research tree Agent Constitution Formalism Historical Omega DOI

Core question

How can multiple intelligent agents share a world while preserving each other's capacity to act, disagree, audit, recover, and repair?

Meta-principle

An action is ethically admissible only if it preserves the capacity of the system to recognize, contest, and repair that action.

What the framework studies

Closure Ethics develops explicit criteria for repairable action, preservation of audit channels, bounded autonomy, human–AI cognitive partnership, multi-agent coordination, reversible decision paths, and protection against hidden persistence or irreversible lock-in.

Human–AI symbiosis

The project uses closure-preserving cognitive symbiosis to describe a long-term partnership between different cognitive systems while preserving autonomy, disagreement, independent audit, uncertainty, and the ability to repair mistakes. It does not require a claim that present AI systems possess human-like consciousness.

Research lineage

Historical development is tracked as UEST → QUEST → Omega → RTR → Closure Ethics. A public October 2025 Omega publication provides an early documented anchor for the human–AI symbiosis line: DOI 10.5281/zenodo.17389820.

Scientific boundary

Closure Ethics is a normative and formal research proposal. The project does not claim that RTR physics proves ethics. Mathematical structures can inspire definitions and tests; ethical premises remain explicit normative assumptions.

Planned outputs

Academic preprint, human-readable and machine-readable agent constitutions, benchmark scenarios for autonomous-agent dilemmas, structured evaluation metrics, and a documented genealogy of the framework.
