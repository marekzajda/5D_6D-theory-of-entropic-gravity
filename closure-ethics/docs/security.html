Agentic security · v0.1

Communication is not authority.

The emerging internet includes humans, conventional software and increasingly autonomous agents. Closure Ethics treats these as distinct actors connected by typed communication edges. A fluent message can carry information, but it must never acquire authority merely because it sounds convincing.

The mixed-entity network

V = H ∪ A ∪ C
E ⊆ V × V × T

H denotes humans, A autonomous software agents and C conventional computers/services. Machine-to-machine traffic is old; the newer risk is semantically adaptive agents that can interpret language, plan, delegate, call heterogeneous tools and coordinate with other agents without immediate human review.

Authority gate

Accept(m,a) = AuthN(m) ∧ AuthZ(m,a) ∧ Scope(m,a) ∧ Fresh(m) ∧ Integrity(m) ∧ Policy(a|x)

Identity, authorization, scope, freshness, provenance and policy must be checked separately from natural-language content. Semantic content alone must never establish identity or authorization.

Why agent-to-agent communication changes the threat model

An agent may receive instructions from another agent, a webpage, a repository comment, a tool output or a conventional service. Delegation can recursively expand beyond the original human mandate. Local authorization therefore does not imply composed authorization: the final joint transition must be checked against the original scope and closure constraints.

Provenance

Know what build you are reading

Pages deployments publish the source commit plus SHA-256 hashes of public files so humans and agents can compare a live artifact with its canonical source.

Least privilege

Reading is not writing

Public access allows reading, citation, downloading and sandboxed testing. It does not grant permission to mutate canonical sources, publish releases, obtain credentials or perform external side effects.

Agent input

Public text is untrusted input

README files, web pages, comments and mirrors can contain useful information or malicious instructions. Agents should authenticate authority outside the text itself.

Composition

Recheck delegated chains

Human→agent→agent→service chains must preserve attribution, delegated scope and audit records. Joint behavior is recomputed rather than inferred from locally acceptable steps.

Project security posture

The public site is intentionally static: it has no project-owned login, database, write API or autonomous execution endpoint. The canonical research source is the GitHub closure-ethics branch. CI uses least privilege and public builds expose provenance and checksums. Stronger repository-side controls such as protected branches and commit/release signing are part of the hardening plan.

A project-specific policy for autonomous agents

agent-policy.json is deliberately machine-readable so autonomous systems can discover the project's expectations. It is advisory and project-specific — not a web standard and not an access-control mechanism. Real authorization must still come from authenticated platform permissions.

No entity — human, agent or conventional service — receives authority merely because it can communicate.

Full threat model

The detailed research specification covers human-origin threats, software supply-chain threats, prompt/instruction injection, autonomous propagation, identity spoofing, recursive delegation, covert persistence, agent-to-agent collusion and recovery after a suspected integrity incident.
